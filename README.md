# Аркана

Матрица судьбы (22 аркана), совместимость, карта здоровья, прогноз по годам, натальная карта, синастрия и транзиты. Статический сайт для GitHub Pages: все расчёты выполняются в браузере, данные никуда не отправляются.

## Структура

- `index.html` — страница
- `css/style.css` — стили (ар-деко: изумруд, латунь, терракота; шрифты Oranienbaum + Raleway)
- `js/matrix.js` — расчёт матрицы
- `js/arcana.js` — описания 22 арканов и позиций
- `js/app.js` — интерфейс: форма, схема, карточки, сохранение, ссылки
- `js/story.js` — картинка для сторис
- `js/natal.js` — астрологические расчёты (карта, дома, аспекты, синастрия, транзиты)
- `js/natal-ui.js`, `js/natal-texts.js`, `js/natal-signs.js`, `js/natal-houses.js` — натальная карта
- `js/syn-ui.js`, `js/syn-texts.js` — синастрия
- `js/transit-ui.js`, `js/transit-texts.js` — транзиты
- `js/biwheel.js` — двойной круг; `js/place-field.js` — поля даты, времени и места
- `vendor/astronomy.min.js` — [astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19 (MIT), положения планет

Поиск городов — [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) (бесплатно, без ключа).

## Локальный запуск

Модули JavaScript не работают при открытии файла двойным кликом, нужен локальный сервер:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Ссылки на матрицу

Матрицу можно открыть по ссылке: `…/#d=15.03.1995&n=Аня`, пару — `…/#p1=…&p2=…`, натальную карту — `…/#nd=…&nt=…&lat=…&lon=…&tz=…`.

## Обновления и кэш

К файлам в `index.html` и к импортам в `js/*.js` добавлен номер версии (`?v=7`).
При каждом обновлении сайта увеличивай его — иначе браузеры могут показать смесь старых и новых файлов.
